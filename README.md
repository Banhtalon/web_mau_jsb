---

## 📖 Giới Thiệu Tổng Quan

Thư mục này chứa **10 dự án website mẫu hoàn chỉnh** dành cho học viên và giảng viên khóa học **Web Basic (HTML5 & CSS3)** tại MindX Technology School.

Trang web tổng hợp trung tâm (`index.html`) được xây dựng chuyên nghiệp, cung cấp trải nghiệm:
- **Khám phá trực quan:** Tìm kiếm nhanh, lọc theo 5 danh mục đề tài, xem số lượng trang và độ khó.
- **Live Preview Simulator:** Giả lập kích thước đa thiết bị (**Desktop**, **Tablet 768px**, **Mobile 390px**) ngay trên trang web mà không cần rời màn hình.
- **Ma trận kỹ năng:** Đối chiếu kỹ thuật HTML5, Flexbox, Grid, Form, CSS Variables của từng đề tài.
- **Hỗ trợ Dark Mode:** Chuyển đổi giao diện Sáng / Tối linh hoạt.

## 💻 Cách Chạy & Trải Nghiệm

### Cách 1: Mở Trực Tiếp Bằng Trình Duyệt
1. Điều hướng đến thư mục `SPCK mẫu`.
2. Nhấp đúp chuột vào file `index.html` để mở trang tổng hợp.
3. Nhấp **"Live Preview"** để xem giả lập trên máy tính, iPad, điện thoại; hoặc nhấp **"Mở Tab Mới"** để trải nghiệm riêng từng website.

### Cách 2: Sử Dụng Live Server Trong VS Code (Khuyên Dùng)
1. Mở thư mục `SPCK mẫu` trong **Visual Studio Code**.
2. Cài đặt tiện ích mở rộng **Live Server** (Ritwick Dey).
3. Nhấp chuột phải vào `index.html` và chọn **"Open with Live Server"** (hoặc nhấn tổ hợp phím `Alt + L, Alt + O`).
4. Trình duyệt sẽ tự động mở tại địa chỉ `http://127.0.0.1:5500/index.html`.

## ⌨️ Phím Tắt Tiện Ích

- Nhấn phím `/` hoặc `Ctrl + K`: Nhảy nhanh vào ô tìm kiếm đề tài.
- Nhấn phím `Esc`: Đóng cửa sổ xem thử (Live Preview modal).
- Nút **"Khám Phá Ngẫu Nhiên"**: Chọn ngẫu nhiên 1 trong 10 website để lấy ý tưởng làm bài.
- Nút **"🌙 / ☀️"**: Chuyển đổi qua lại giữa giao diện Tối và Sáng.
